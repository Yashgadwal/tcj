# TCJ — The Gourmet Store (The Convenience Junction)

An ultra-luxury, immersive e-commerce web experience featuring high-performance cinematic scroll animations powered by GSAP and ScrollTrigger.

## ? Experience Chapters & Scroll Animations
- **Storefront Walk-In**: Cinematic seamless entrance into the flagship boutique.
- **Sub-Zero Drinks Experience**: Liquid physics and chilled international hydration icons (Prime, Monster Energy, Japanese Ramune).
- **Spicy Snacks Explosion**: Fiery spice dust crunch (Takis Fuego, Samyang Buldak 2X, Cheetos Flamin'' Hot).
- **Sweet Candy Wonderland**: Confectionery particle burst (Haribo Goldbären, Skittles, Nerds Gummy Clusters).
- **Dubai Chocolate Universe**: Fresh daily viral pistachio & knafeh chocolate.

## ?? Key Features
- **60FPS Frame-by-Frame Scrubbing Engine**: Canvas-based hardware-accelerated rendering.
- **Dual-Device Optimization**: Tailored 16:9 landscape (desktop) & 9:16 portrait (mobile) assets.
- **Zero Watermark Guarantee**: Custom branded TCJ luxury hallmark badges across all visuals.
- **WhatsApp Direct Ordering**: Instant dispatch integration for local Ujjain deliveries.

## ??? Tech Stack
- HTML5 / CSS3 / JavaScript (ES6+)
- Tailwind CSS
- GSAP + ScrollTrigger
- Node.js (Static HTTP & dev server)

## ?? Running Locally
```bash
# Start local server
node server.js
```
Visit `http://localhost:8080/` in your browser.
